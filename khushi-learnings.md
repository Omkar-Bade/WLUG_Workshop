# WLUG Workshop - Session Learnings

**Name:** Khushi Malani

### 1. Git Basics

* Learned what Git is and why version control is useful.
* Learned how to initialize and work with a Git repository.
* Learned how to check the current state of a repository using `git status`.
* Learned how to create and switch between branches.
* Practiced basic Git commands.

### 2. GitHub

* Learned how GitHub is used to host and collaborate on Git repositories.
* Learned how to fork a repository.
* Learned how to clone a repository locally.
* Learned how to connect our local work with GitHub.
* Learned how to push changes to a remote repository.

### 3. Open Source Workflow

* Learned the basic workflow of contributing to an open-source project.
* Understood the purpose of forks and branches.
* Learned how to make changes in our own branch without affecting the main branch.
* Learned how to raise a Pull Request.
* Understood how contributors and maintainers collaborate through GitHub.

### 4. Commands Practiced

* `git clone`
* `git status`
* `git branch`
* `git checkout`
* `git add`
* `git commit`
* `git push`

### 5. Key Takeaway

* Understood that Git and GitHub are not just tools for storing code, but also for collaboration and managing changes.
* Got a practical introduction to how real open-source contributions are made.
* The hands-on approach made the GitHub workflow much easier to understand.

### 6. Feedback

The workshop was a great hands-on introduction to **Git, GitHub, and open-source contribution**. The best part was getting to actually follow the workflow instead of just learning the commands theoretically.

The session made open source feel much more approachable and gave me the confidence to make my first contribution and raise a PR.
